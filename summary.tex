\section{Summary}
\label{sec:summary}
This paper gave an overview of type theory and how it applies
to programming languages.
It showed how important aspects of programming languages
can be specified precisely and formally.
It showed how properties of programming languages can be proven.
It described how computers can aid in formal verification
of properties.
Lastly, it points out many topics that the reader can
investigate further to better understand foundations
underlying programming languages.
